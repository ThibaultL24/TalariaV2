# API and OpenAPI

Request specs are the source of truth for OpenAPI generation via rswag.

Endpoints include:
- `GET /api/entities/:id`
- `GET /api/entities/:id/events`
- `GET /api/events/:id`
- `GET /api/events/:id/evidence`
- `GET /api/map/features`
- `GET /api/timeline`
- `GET /api/search`
- `POST /api/ingestion_runs`
- `POST /api/sources/:source_type/import`
- `POST /api/raw_documents/:id/reprocess`
- `POST /api/raw_candidates/:id/promote`
- `GET /api/admin/review_queue`
